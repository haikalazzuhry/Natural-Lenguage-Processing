## Deskripsi
Tugas ini melakukan preprocessing teks pada dataset ulasan produk e-commerce berbahasa Indonesia, meliputi:
- Informasi dataset (jumlah data, kolom, distribusi label sentimen)
- Case folding
- Cleaning (URL, angka, tanda baca, karakter khusus)
- Tokenisasi
- Stopword removal
- Stemming

## Dataset
[dipawidia/ecommerce-product-reviews-sentiment](https://huggingface.co/datasets/dipawidia/ecommerce-product-reviews-sentiment) (Hugging Face)
